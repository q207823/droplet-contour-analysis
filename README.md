目標
此專案旨在撰寫一個可從水滴截面的輪廓找到接觸角的程式。
input:
point 2D array 分別為(x,y)輪廓座標
horizon 2*2 array 為地平線通過的兩點

output:
在point中找到左右接觸點座標和編號
contact_point 2*2 array 分別為左右接觸點

現有檔案:
curvature_calculator_4 包含理想的圓形測試資料
curvature_calculator_5 模組化的函式

請幫我寫一個第六版的函式 get_contact_point，請注意，第五版雖然已經通過理想測試資料的測試，但實際的水滴輪廓會是由影像處理得到的，並不一定是正圓一一部分，與地面的接觸區域也不一定是完美的直線，所以在撰寫第六版時，不能為了提高正確率使用一些生成測試資料時使用的參數，例如與地面接觸線的長度等等。我使用第五版測試真正的數據時，發現在鈍角接觸角時，常常找到離地平線過高的位置。

我目前整理出接觸點會是以下幾個特徵的交集:
1. 最接近地平線的一群點
2. 曲率變化劇烈的點

現在請你以第五版為基礎，並加入考慮最接近地平線的點，依以下步驟進行驗證，通過後才進入下一階段
1. 驗證資料:curvature_calculator_4 生成的測試資料(理想的測試資料，是一個截掉下半部特定高度的圓，並且加上噪音。)，目標:噪音0.005的情況，在各角度達成95% 以上的辨識正確率。
2. 驗證資料:20260911_test2_1X_10ul_10ms.xlsx以及20260911_test2_1X_10ul_10ms.csv前者的parameter中A5:B6是地平線上的兩點 目標: 輸出[t,contact_point]陣列，並且逐張繪製輪廓圖形並在其上標記座標點，合併儲存成影片讓我檢查。可以使用function中的程式協助你完成
